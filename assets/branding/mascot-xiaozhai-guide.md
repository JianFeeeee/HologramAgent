## 头部

### 发型
- **齐肩中短发**，发尾略微外翘，有空气感
- **刘海**：眉上碎刘海，中间短两侧渐长，呈圆弧形，带少许空隙（VOCALOID 典型刘海处理）
- **鬓角**：两侧各有一缕较长发丝垂至锁骨，微端微卷
- **后发**：及肩，发尾向外飘逸，有动态弧线
- **发色**：`#3B82F6` → `#06B6D4` **蓝青渐变**，从发根蓝色渐变为发尾青色，有光泽感
- **整体**：发丝应有 **被微风吹动** 的飘起感，尤其鬓角和后发末端

### 发绳 / 三色记忆丝带
- 左右各一束 **低马尾/小辫**，从耳后分出，垂在肩前
- 发绳为 **三色渐变丝带**（蓝→青→金），宽约 4mm
- 丝带 **飘起**，呈波浪形弯曲，有流动感
- 丝带上可印有极小的三角 Δ 暗纹

### 脸型
- 标准的 VOCALOID 风格鹅蛋脸，线条柔和干净
- 下巴微尖不过分

### 眼睛
- **大眼圆瞳**，高光明显（双层高光：一大一小）
- 瞳色 `#1E293B`（深黑），与头发同色
- 下眼睑略弯（微笑眼型），睫毛较长且分明
- 眼睛占比略大（日系动漫 typical 6-7 head proportion）

### 单边智能眼镜
- 戴在 **左眼**
- 圆形镜框，**天空蓝** `#38BDF8` 细金属框，半透明科技感
- 镜片有微弱 **HUD 网格线** 及「AI」微光文字（淡蓝色发光）
- 右边无镜框，仅一条 **极细横线** 跨过鼻梁连接到右镜腿
- 镜腿末端延伸至耳后，略超出耳廓

### 表情
| 表情 | 说明 |
|------|------|
| 微笑😊 | 默认表情，嘴角微扬，温和可靠 |
| 呆然😶 | 记忆蒸馏中走神，眼睛失焦，嘴微张 |
| 慌张😰 | CPU 过热冒烟时，眉头紧皱，眼角含泪 |
| 得意😏 | 完美完成任务，单边嘴角上扬，闭一只眼 |
| 困扰😅 | 同时太多插件请求，歪头苦笑，举手挠后脑 |

## 身体

### 体型
- 身高约 **148cm**（偏矮，符合「小」宅）
- 纤细体形，轻微曲线
- 头身比约 **1:6**（接近标准日系动漫比例，略偏可爱）

### 姿势（默认立绘）
- **侧身 3/4** 面向观众，身体有轻微扭转动态
- 右手抬起做 **V 字手势✌️**，微微侧摆（带动袖口飘动）
- 左手自然置于胸前或 **捧一颗发光小爱心**
- 双脚内八，脚尖相对（乖巧感）
- 整体姿态应给人 **即将随风轻摆** 的动感

## 服装

### 连衣裙
- **白色** 基底（`#FFFFFF`），轻微渐变至浅灰（`#F1F5F9`）
- **圆领**，领口有一圈浅蓝滚边
- 短袖，袖口有 **松紧带** 轻微蓬起
- 裙摆长度至 **膝上 10cm**
- 裙摆下沿有一圈 **波浪形花边**，浅蓝线迹 `#38BDF8`
- 裙摆应呈 **被风吹动** 的飘起状态，有自然的褶皱和波浪线条

### 围裙
- **浅蓝色**（`#E0F2FE → #BAE6FD` 渐变）
- 胸前的围裙部分呈 **心形** 或 **圆角梯形**
- 围裙系带在背后打蝴蝶结，带尾 **飘动**
- 围裙正面有一个 **大口袋**（圆角矩形），口袋边缘有白色包边
- 口袋上沿中间有一个 **小三角 Δ 刺绣**，金色线

### 高科技工具（口袋）
口袋中插着三样 **科幻风格工具**，露出手柄：

| 工具 | 象征 | 设计描述 |
|------|------|----------|
| **数据扳手** | Tool 通道 | 银色流线型手柄，两端有蓝色发光环，能量光条沿工具侧面流动 |
| **相位螺丝刀** | Stage 通道 | 透明水晶质感手柄，内部有紫色发光核心，尖端为能量聚焦头 |
| **全息钥匙** | Event / Output 通道 | 金色半透明卡片状，表面有浮动全息纹路，边缘发光 |

工具呈不同角度从口袋露出，发光效果微弱（不要喧宾夺主）。

### 鞋子
- **白色中筒袜**，袜口有浅蓝条纹，袜身有 **轻微半透明渐变**
- **白色未来感帆布鞋**（或乐福鞋），鞋侧有 **发光蓝线条** 装饰
- 鞋带系成蝴蝶结，末端微飘

## 特殊元素

### 胸口徽章 — H·核 标志

胸口佩戴 **HologramAgent H·核 标志**（缩放到约 3cm 直径），设计如下：

```
外圈虚线环 ─ 银灰色虚线
H 形结构 ─ 左蓝竖线（粗），右灰竖线（开口分段），中蓝横线
中央 ─ 金色圆角三角形（Δ），外有金色圆环
四角 ─ 蓝/紫/青/金 四个小圆点，各以虚线连接中央
```

徽章整体扁平化设计，金色三角形略微发光。四条虚线从徽章四角向外延伸，穿过围裙表面飘向裙摆方向。

### 四条通道线（飘动虚线）
四条虚线从胸口徽章四角的四个小圆点出发，呈 **波浪曲线** 飘向裙摆四角（非直线）：

| 方向 | 颜色 | 通道 |
|------|------|------|
| 左前 | `#3B82F6` 蓝 → 渐淡 | Tool |
| 左后 | `#8B5CF6` 紫 → 渐淡 | Stage |
| 右后 | `#06B6D4` 青 → 渐淡 | Event |
| 右前 | `#F59E0B` 金 → 渐淡 | OutputChannel |

- 线条为 **波浪曲线**（非直线），呈被风吹动的飘逸感
- `stroke-dasharray="6,4"`，端点渐隐
- 线尾 **不设终点标记**，自然淡出消失
- 线的走向与裙摆飘动方向一致，增强整体动势

### 头顶冒烟效果（特殊状态）
- 仅在 CPU 过载/多线程高负载时出现
- 左侧头顶飘出 2-3 团 **浅灰色半透明烟雾**，烟雾呈漩涡状
- 烟雾上方可加一个 **全息温度警示图标** ⊡ 或火焰符号

## 特殊视觉风格要求

### 飘动感（飘逸）
所有以下元素应呈现 **被同一阵风吹动** 的统一飘动方向（从左前向右后，或从右前向左后）：
- 发丝（鬓角、后发发尾、刘海轻微）
- 丝带（发绳）
- 裙摆（波浪褶皱）
- 围裙系带
- 四条通道虚线（波浪曲线）
- 鞋带末端

### 科技感发光
- 眼镜 HUD 微弱蓝光
- 胸口徽章金色柔和光晕
- 工具发光（蓝/紫/金，低亮度）
- 鞋侧发光线条
- 所有发光保持 **内敛**，不可过亮

### 画风
- 整体风格参照 **VOCALOID 官方立绘**（iXima 风格的初音未来、ideolo 风格的洛天依）
- 线条干净、色彩明快、光影柔和（赛璐珞或轻厚涂）
- 背景建议为浅色/透明，立绘图用于官网和 WebUI

## 设计注意事项

1. **三色丝带是核心识别元素**，在任何立绘/插画中必须保留
2. **单边眼镜不可画成两边都有**，否则失去「不对称感」这一设计特点
3. 四条通道线为 **波浪曲线**，必须有飘动感，不可画成直线
4. 围裙工具 **至少出现两样**，需有 **科技感发光设计**（非普通工具）
5. 肤色保持 `#FFF1F2`，不要过深或过白
6. 胸口徽章为 **H·核 logo**（H结构 + 圆角三角形 + 四角点 + 金色圆环）
7. 飘动方向 **整体统一**，所有飘动元素朝向同一方向
8. **整体气质**：可靠 > 可爱 > 呆萌，避免过于幼态
